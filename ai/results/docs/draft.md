**목표** 합성 주간 매출 원본을 스프레드시트로 불러와 지점×주 단위로 정리하고, 수식 합계·건수를 원본과 대조해 수작업 취합 절차를 수치로 측정한다(기준 소요 시간기록 확보, 값 전사 오류 지점 식별).

**수행 단계**

**제출물** 정제·대조 완료 워크북(.xlsx, 원본대조 시트 포함) / 1쪽 결과 요약: 지점×주 표, 합계·건수 대조 결과, 단계별 소요 시간 기록 / 데이터 가정 메모(파일 구조·항목 정의·제외 항목)

## [고급] 주간 매출 이상 탐지·알림식 플래그가 포함된 검토용 리포트(취합 자동화 확장)

**목표** 중급 취합 자동화를 확장해 지점×주 매출의 이상 패턴(급증·급감·결측/중복 의심)을 규칙+기초 통계로 탐지하고 사유 코드를 붙인 '검토 필요' 요약을 리포트에 실어, 담당자가 확인해야 할 항목만 남긴다.

**범위** 범위 안: 기준 기간(가정: 최소 8~12주) 확보, 지점별 주 매출의 전주 대비 증감률·분포(사분위/중위수 기준) 산출, 임계값·규칙 명시, 플래그 사유 코드와 근거 값 기록, 주간 리포트에 검토 섹션 추가, 요약 통계·로그 출력. 범위 밖: 원인 규명(영업·프로모션 데이터 없음), 고도화된 ML/실시간 스트리밍, 사내 알림·메일·메신저 연동, 의사결정 자동 실행·수정 권한, 실제 데이터로의 일반화 보장.

**수행 단계**

- 1) 분석 전제 가정: 기준 기간 길이, 지점 수, 단위, 결측/이상 정의(이상은 '자동 판단'이 아니라 '검토 후보 표시'로 한정).
- 2) 중급 산출물을 입력으로 받아 지점×주 지표(매출, 건수, 전주 대비 증감률, 분포 위치)를 계산한다.
- 3) 규칙을 문서화한다(가정 예: |증감률| 임계 초과, 사분위 기준 이탈, 결측/중복 의심) — 임계값은 가정임을 명시하고 설정 블록으로 분리.
- 4) 지점×주별 플래그와 사유 코드·근거 수치를 생성하고, 오탐 가능성을 줄이기 위해 최소 건수/최소 금액 조건 같은 보조 조건도 기록한다.
- 5) 취합 리포트에 '검토 필요 요약'(플래그 수, 상위 항목, 근거 값)과 상세 위치를 추가한다.
- 6) 요약 통계·플래그 분포·로그를 남기고 다시 실행해 동일 결과를 확인한다(재현성) + 플래그 검증 절차(오탐 확인 방법)를 문서화한다.

**제출물** 확장 스크립트(취합→지표→탐지→리포트, 모듈 분리) / 플래그 포함 주간 검토용 리포트(합성 입력 기준) / 규칙·임계값·전제 가정 문서(가정 변경 시 파라미터/설정으로 조정) / 검증 요약: 플래그 수·분포, 재현성 확인 결과, 오탐 검토 절차 메모

**기술 태그** `pandas 지표 계산(증감률·분포 요약)` `기초 통계 개념(사분위·이상 패턴 판단)` `규칙 기반 탐지와 사유 코드 설계` `로그·재현성·가정 문서화`
